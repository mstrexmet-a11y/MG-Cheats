MG CHEATS 1.0 — Minecraft Java 1.20.1 / Forge 47.x
====================================================

ВНИМАНИЕ: это исходный проект, не готовый JAR. Его нужно собрать.

Функции в первой заготовке:
- ClickGUI на Right Shift
- AutoSprint
- Fullbright (пока включён — повышает gamma)
- KillAura для локального тестирования; может атаковать ближайших живых сущностей
- Reach Display — пункт меню-заготовка, отображение пока не реализовано

Сборка на Windows:
1. Установи JDK 17.
2. Распакуй ZIP в папку без кириллицы в пути, например D:\MG-Cheats.
3. Открой терминал в этой папке.
4. Выполни: gradlew build
   Если файла gradlew нет, открой проект через IntelliJ IDEA с Gradle и разреши Gradle скачать зависимости.
5. Готовый JAR появится в build\libs\mgcheats-1.0.0.jar
6. Скопируй JAR в .minecraft\mods. Установи Forge 1.20.1 (ветка 47.x).

Для локальных миров и серверов, где такие модификации разрешены. Не используй боевые функции там, где они запрещены правилами сервера.

Примечание: исходники подготовлены как стартовая версия; сборка может потребовать мелких исправлений в зависимости от установленного Gradle/Forge окружения.


СБОРКА ЧЕРЕЗ GITHUB ACTIONS (если на компьютере нет Gradle):
1. Создай новый репозиторий на GitHub.
2. Загрузи в него содержимое этой папки (включая скрытую папку .github).
3. Открой вкладку Actions и запусти workflow "Build MG Cheats" через Run workflow.
4. После успешного выполнения открой запуск workflow и скачай артефакт MG-Cheats-1.0-JAR.

Примечание: workflow собирает проект на сервере GitHub; он не означает, что проект уже был собран в этом ZIP.
